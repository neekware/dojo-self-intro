# Dojo Power Showcase — Killer Main Website Video

## Goal
A ~90–120s cinematic capability reel for the main website. **No Val on camera.** Origin film stays for "who created you." This video proves Dojo can **code, image, video, edit, audio, stitch, flyover, try-on**.

## Format
- 1920×1080, 30fps, 16:9
- Remotion composition + real Dojo-generated media assets
- Dark cinematic grade, amber/orange Dojo accent
- Narration + kinetic type + live demos

## Beat sheet (~105s)

| # | Section | Time | What we show |
|---|---------|------|--------------|
| 0 | Cold open | 0–5s | Logo mark, "DOJO" sting |
| 1 | Hook | 5–15s | "Not a chatbot. A creative studio that ships." |
| 2 | Code | 15–28s | Code typing / fix / ship moment |
| 3 | Image | 28–42s | Product shot + portrait + arch viz grid |
| 4 | Video motion | 42–54s | Still → motion, promo energy |
| 5 | Flyover | 54–64s | Cinematic drone pass on building |
| 6 | Try-on | 64–76s | Person + garment virtual fit |
| 7 | Audio | 76–86s | Voice synthesis waveform + spoken line |
| 8 | Stitch | 86–96s | Timeline assemble — clips snap together |
| 9 | Outro | 96–105s | "Anyone can code. Anyone can create." + dojoworkspace.io |

## Build phases
1. Scaffold Remotion in `ads/`
2. Generate media assets (images, short clips, VO)
3. Build scene components + master composition
4. Preview in Studio, iterate timing
5. Render final MP4
6. Optional: drop into marketing site later

## Asset list to generate
- Brand backgrounds / abstract motion plates
- Product hero still
- Fashion person + garment (try-on)
- Architecture building still → flyover clip
- Character portrait → subtle animation
- Narrator VO segments
- Code scene (styled UI mock, not screen-record required v1)

## Rules
- No creator face in main reel
- No letterbox bars baked into generated media
- Prefer real Dojo-generated media over stock
- Remotion owns titles, transitions, kinetic type, final stitch
