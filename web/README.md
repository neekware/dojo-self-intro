# Solstice alpine editorial

Cinematic single-page fashion-film landing page.

## Open

From the repository root:

    python3 -m http.server 8765 --directory web

Then open `http://127.0.0.1:8765/`.

## Structure

- `index.html` — page structure and editorial content
- `styles.css` — responsive cinematic visual system
- `main.js` — video audio controls and progress state
- `assets/brand/` — deliberate self-contained copies of the Dojo logo and torii mark for this standalone demo
- `assets/images/alpine-swimwear-editorial.jpg` — live poster
- `assets/videos/alpine-swimwear-walk.mp4` — live 15-second H.264/AAC film
- `assets/work/` — unused creative explorations retained for provenance; filenames include honest resolution labels and are not loaded by the page
